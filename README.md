# Adonai Guest House Website

Built with HTML5, Tailwind CSS v4, vanilla JavaScript, Vite, GSAP and Lucide icons.

## Run locally
1. Extract the ZIP and open the `adonai-guest-house` folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite (usually http://localhost:5173/).

Keep the terminal running. Press Ctrl+C to stop the server.

## Production
Run `npm run build`, then `npm run preview`.

## Before publishing
Replace illustrative stock photos with real property photographs; confirm room categories, rates, actual menu and prices; verify the WhatsApp contact; add the real Facebook page URL. The booking form opens WhatsApp and the guest must press Send. It does not itself confirm a reservation.

Room and property imagery is illustrative or externally hosted; menu imagery is AI-generated illustration, not verified photography from the guest house kitchen.


## Property photographs
The hotel-specific exterior, bedroom and dining photographs in this version are referenced from the ADONAI GUESTHOUSE public photo gallery on Hotels.com. The website uses the listing's hosted image URLs rather than copying the image files into this project. Before publishing commercially, confirm that Adonai Guest House has permission to reuse these photographs and that the listing provider permits hotlinking. If you have the original image files, replace the hosted URLs with locally stored files in `public/images/` for better long-term reliability.

The food/menu photographs remain illustrative examples and should be replaced with actual menu photography and confirmed dishes/prices.

## Brand colours
The primary brand colour is cream yellow `#fffbc4`. Royal blue `#2577aa` and bright blue `#0c92d0` remain as supporting accent colours for readable text, links and details.


### Food imagery
The six menu images are locally stored in `public/images/food/`. They are AI-generated illustrative food visuals (including Nigerian-style jollof rice), not documentary photographs of dishes actually prepared at Adonai Guest House. Replace them with the guest house's own food photographs when available, and confirm menu availability and prices before publishing.
